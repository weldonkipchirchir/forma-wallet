USDT on Ethereum is not the same contract as USDT on Polygon

ERC-20 contracts live on EVM networks. Solana uses token mint addresses and token accounts. TRON uses its own addresses and TRC-20 contracts. Obtain the exact chain and contract/mint from the issuer's official documentation before adding an asset. Fake contracts can copy names, symbols and logos.

Can tokens appear automatically?

Yes. Wallets can use chain data or indexers to find token accounts and transfers. Discovery is not a security endorsement: spam tokens and misleading events exist. Forma's EVM discovery searches a bounded recent block window, checks contract code and positive balances, and shows candidates for you to confirm. Optional auto-find searches on opening the token page; it does not automatically trust or approve a token.

How do I add a token in Forma?
  1. Select the exact test network.
  2. Open Tokens and use Find tokens, then review and add a candidate.
  3. If it is missing, paste the verified token contract or mint address into Import token.
  4. Confirm the network, decimals and displayed balance. Imported labels remain unverified.
Why is a token missing?

It may be on another network, older than the discovery window, unsupported by the adapter, or absent because the RPC/indexer is unavailable. Try a verified manual import. A missing UI entry does not move or destroy an on-chain asset.

What about SOL shown on Ethereum or Polygon?

Native SOL is a Solana asset. A contract labelled SOL on an EVM network is a separate wrapped, bridged or potentially fake token. Check its issuer, bridge and contract. Adding a token does not bridge funds.

What changes in a real-world wallet?

Before receiving a real asset, both sender and recipient must agree on the exact network. Select that network when withdrawing from an exchange. Keep its native fee asset available. Testnet tokens have no real monetary value; production transfers, swaps and cards require separately reviewed mainnet and provider integrations.

Forma remains a testnet prototype. Do not send real funds or import a real-funded recovery phrase. Token discovery has coverage limits and cannot guarantee authenticity.
